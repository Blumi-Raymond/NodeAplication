# Vacation Apartments Platform — Client

A frontend application for a vacation apartment platform, built as part of a full-stack web development project.

## Technologies

- React
- JavaScript
- HTML and CSS

## Features

- User interface for the vacation apartments platform.
- Search-oriented interface for browsing available information.

## Getting Started

1. Clone this repository.
2. Install the project dependencies using `npm install`.
3. Run the application using the start command defined in `package.json`.
